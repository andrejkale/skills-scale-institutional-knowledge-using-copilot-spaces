# Contributing

Thanks for helping improve the knowledge base!

How to contribute

1. Find the right place to add content under `docs/` or open an issue to discuss big changes.
2. For documentation changes, open a PR targeting `main` with a descriptive title and link to the related issue.
3. Use the issue and PR templates to help maintainers triage and review.

Style
- Prefer clear, action-oriented steps.
- Keep guidance short and link to authoritative references.

Maintainers
- Tag @repo-maintainers on important changes.
